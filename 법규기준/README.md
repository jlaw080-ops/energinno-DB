# 법규기준

에너지 경제성 평가(VE, LCC)와 설비 설계 검토에 근거로 쓰이는 **법령·고시·규정 원문** 모음입니다.

## 폴더 구조

```
법규기준/
├── 데이터센터/    — 데이터센터 전력설비 법정 기준
└── 전력계통/      — 한전 계통연결 관련 규정
```

### 근거 법령

- **민간**: 정보통신망법 제46조 및 시행령 제37조제2항 → 「집적정보 통신시설 보호지침」(과학기술정보통신부고시 제2024-19호, 시행 2024. 6. 1.)
- **공공**: 「행정기관 및 공공기관 정보자원 통합기준」 별표3 정보시스템 운영시설 안정성 기준

### ⚠ 민간/공공 기준 차이

발전기 연료 보유 기준이 **민간 2시간 / 공공 12시간**으로 6배 차이가 납니다. 발전기 용량 산정 대상 부하도 다릅니다. 기획 단계에서 발주처 성격을 먼저 확정해야 합니다. 상세는 정리 노트 2-4절 참조.

### 활용 포인트

표본공정 소요일수 표에서 **154kV 변압기 증설 12개월 vs 154kV 변전소 신설 78개월**의 차이가 사업 일정을 6년 이상 좌우합니다. 부지 검토 시 인접 변전소 여유용량 확인이 최우선입니다.

## 파일명 규칙

원문은 저장소 공통 규칙인 `시행일(YYYY-MM-DD)_자료명.확장자`를 따릅니다.

**예외**: `정보시스템_운영시설_안정성_기준_별표3.pdf`는 문서에 시행일이 표기되어 있지 않아 날짜를 붙이지 않았습니다. 시행일이 확인되면 규칙에 맞게 변경해 주세요.

## 자료 종류 표기

- **원문** — 발행기관이 배포한 파일을 그대로 보관한 것. 법적 근거로 인용 가능
- **추출본** — 웹 본문을 텍스트로 변환한 것. 참고용이며, 인용 시 국가법령정보센터 원문 확인 필요
- **정리** — 원문을 읽고 작성한 검토 노트. 원문이 아님

## 자료 추가 시

1. 성격에 맞는 하위 폴더에 원문 파일을 넣습니다.
2. 파일명을 `시행일_자료명` 형식으로 바꿉니다.
3. 위 표에 파일과 자료 종류를 추가합니다.
4. 개정본을 받은 경우, 구버전은 지우지 말고 시행일로 구분해 함께 보관합니다.
