# 단가정보

에너지 경제성 평가(VE, LCC)에 쓰이는 **공공요금 원문 자료** 모음입니다.
한국전력공사 전기요금표와 한국가스공사 천연가스 요금자료를 시행일 기준으로 정리했습니다.

## 폴더 구조

```
단가정보/
├── 전기요금/
│   ├── 종합/          — 전체 종별(주택용·일반용·교육용·산업용·농사용·가로등) 요금표
│   ├── 주택용고압/     — 주택용전력 고압 사용량별 요금표
│   └── 주택용저압/     — 주택용전력 저압 사용량별 요금표
└── 가스요금/           — 한국가스공사 천연가스 요금 (CSV)
```

**파일명 규칙:** `시행일(YYYY-MM-DD)_자료명.확장자`
시행일 순으로 자동 정렬되므로, 평가 기준일에 맞는 요금표를 바로 찾을 수 있습니다.

## 가스요금 (한국가스공사)

| 파일 | 내용 | 범위 | 인코딩 |
|---|---|---|---|
| `2022-12-01_한국가스공사_발전용천연가스요금.csv` | 발전용 천연가스 원료비·공급비 월별 시계열 (원/Nm³, 원/GJ) | 2008-01 ~ 2022-12 (180개월) | UTF-8 |
| `2026-09-01_한국가스공사_천연가스요금정보.csv` | 용도별 도매요금 단가 (원료비·공급비용·도매요금) | 2026-09-01 기준 | **CP949** |

**용도별 요금정보에 포함된 구분:** 민수용(주택용, 일반용), 상업용(업무난방용, 냉난방공조용, 산업용, 수송용), 도시가스발전용(열병합용, 연료전지용, 열전용설비용)

### CP949 파일 읽는 방법

`2026-09-01_한국가스공사_천연가스요금정보.csv`는 CP949(euc-kr) 인코딩입니다.
그대로 열면 한글이 깨지므로 인코딩을 지정해야 합니다.

```python
import pandas as pd
df = pd.read_csv("단가정보/가스요금/2026-09-01_한국가스공사_천연가스요금정보.csv", encoding="cp949")
```

1. 원문 파일을 받아 종별에 맞는 폴더에 넣습니다.
2. 파일명을 `시행일(YYYY-MM-DD)_자료명.확장자` 형식으로 바꿉니다.
3. 위 보유 현황 표에 시행일을 추가합니다.
