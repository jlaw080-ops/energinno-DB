# energinno-DB

ENERGINNO 에너지 경제성 평가용 **기초 데이터 저장소**입니다.
VE·LCC 검토, ZEB 사업성 분석 등에 반복적으로 쓰이는 공공요금·단가 자료와 법규 원문을 모아 둡니다.

## 구조

```
단가정보/          — 공공요금 원문 자료
├── 전기요금/      — 한국전력공사 시행일별 요금표 (PDF)
└── 가스요금/      — 한국가스공사 천연가스 요금 (CSV)

법규기준/          — 법령·고시·규정 원문
├── 데이터센터/    — 데이터센터 전력설비 법정 기준
└── 전력계통/      — 한전 계통연결 규정
```

자료 목록과 보유 현황은 각 폴더의 README에 정리해 두었습니다.

- [`단가정보/README.md`](단가정보/README.md) — 시행일별 요금표 보유 현황
- [`법규기준/README.md`](법규기준/README.md) — 법령별 원문 목록과 활용 포인트

## 파일명 규칙

모든 자료는 `시행일(YYYY-MM-DD)_자료명.확장자` 형식입니다.
시행일 순으로 정렬되므로 평가 기준일에 해당하는 자료를 바로 찾을 수 있습니다.

```
2024-01-01_전기요금표_종합.pdf
2026-09-01_한국가스공사_천연가스요금정보.csv
```

## 자료 추가 시

1. 성격에 맞는 하위 폴더에 원문 파일을 넣습니다.
2. 파일명을 위 규칙에 맞게 바꿉니다.
3. 해당 폴더의 `README.md` 보유 현황을 갱신합니다.
